# Diploma Projects

University thesis work, one directory per degree.

## `bachelor-unilab/`

**unilab** — bachelor thesis (2022). Django application, cookiecutter-django
layout, Docker Compose for local and production, PostgreSQL.

## `master-quized/`

**QuizEd** — master thesis (2025). Full-stack TypeScript application with a
FastAPI backend, React frontend, and a separate AI service for quiz feedback.

Each directory keeps its own README, Docker setup, and dependency manifests,
and retains its original commit history.
